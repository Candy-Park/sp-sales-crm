원문과 이전 검토 근거를 보존하고, 초안·복사를 실제 발송과 구분해 업무 상태 오판을 줄였다. 받은 답변만으로 질문을 완료하지 않으며 미답변/부분 답변이나 조회 실패·잘림이 있으면 문의 종료를 막는다. 저장 결과가 불확실할 때 입력과 요청 식별자를 유지한다.

수집 연결의 최종 로컬 Node 72개, Python 35개 테스트 및 브라우저 빌드를 통과했다. API/회신 UI 테스트는 가상 네트워크 응답을 사용한다. 제품·회신 DB와 실제 로그인 화면에서 합성 자료의 업무 흐름을 검증했다. 실제 고객 회신·메일 발송 검수와 구분한다. 전체 MVP 완료를 의미하지 않는다.

AI 서비스·모델·비용은 아직 선택하지 않아 호출하지 않는다. Outlook 실제 서버 전송 E2E·두 세션 경합·백업 복원 검증·1주 실사용은 남아 있다. 백그라운드 자동 실행·인증정보 영구 보관·배포는 이번 승인 범위에 포함하지 않는다. 기존 CRM과 Supabase sp-crm, 무료 플랜과 로컬 전용 Git 조건을 유지했다.
