# SP 로고·공통 색상 적용

2026-10-07. 사용자가 첨부한 Source Photonics 로고의 배경 제거와 CRM 전체 색상 적용을 요청했다.

## 변경과 보존

- 첨부 JPEG의 대표 초록 `#7DCA26`, 남색 `#252D7E`를 공통 색상으로 적용했다. 초록은 상단 선·강조·선택/포커스 표시에, 남색은 제목·링크·버튼에 사용한다. 작은 초록 글자는 더 어두운 `#467B14`로 표시하고 오류의 빨간색은 유지한다.
- 이미지 편집 도구의 배경 제거 결과는 색 번짐 때문에 채택하지 않았다. 동일한 형태의 기존 공식 투명 PNG를 사용해 SP 심벌과 검정 회사명의 형태·단색을 유지했다. 첨부 JPEG와 원본 자산은 변경하지 않았다.
- `web/assets/sp-logo-transparent.png`를 추가하고 로그인·헤더의 텍스트 워드마크를 실제 로고로 교체했다. `web/style.css`의 공통 폼·메뉴·업무 요약·제품 카드에도 같은 팔레트를 적용했다.
- `tools/build.mjs`, `tools/dev-server.mjs`, `tools/ui-fixture-server.mjs`에 로고 복사·정적 응답을 추가했다. UI 식별자·업무 로직·인증·DB는 바꾸지 않았다.
- 이전 스타일·HTML·빌드/서버·개발 보고서의 사본은 D 드라이브 산출물의 `2026-10-07-brand-before/`에 보관했다. 투명 로고, 검사 기록과 검수 화면도 같은 프로젝트의 outputs/에 저장했다. 개인 원본 경로·자격증명·메일 원문은 Git에 넣지 않았다.

## 검증

- Node 72개 검사와 브라우저 빌드 통과. `git diff --check` 통과.
- PNG 238×65, 알파 범위 0~255, 완전 투명 픽셀 11,049개. SHA-256: `cb656350fc43ca6dae952b79bb6084564f3ad681eb64bedcc63ca5b53a84fc11`.
- 실제 로컬 서버의 로고 요청은 HTTP 200, `image/png`, 3,305바이트로 확인했다.
- Chrome 실제 로컬 로그인 화면의 로고·색상을 확인했다. 격리된 합성 계정의 Dashboard와 문의 등록 화면도 확인했으며 고객 데이터나 실제 메일을 저장하지 않았다. 합성 프리뷰는 기존 동결 산출물을 덮어쓰지 않는 별도 출력 폴더를 사용했다.
- 로그인한 기존 업무 탭은 새로고침하지 않았다. 새 구현의 로그인 대기 탭에서 스타일을 확인했고 실제 로그인 후 브랜드 시각 확인은 아직 하지 않았다.

## 반영·남은 작업·복원

이번 관련 파일만 `Apply Source Photonics logo and brand colors to CRM` 메시지로 로컬 커밋한다. 원격·push·배포는 하지 않는다. 상세 커밋 ID는 Git 이력으로 확인할 수 있다.

기존 Outlook 작업의 실제 서버 전송·문의 연결 E2E는 사용자 로그인 이후 계속할 수 있다. 서버 영수증 0건 상태이며 이번 색상 적용으로 수집 완료를 주장하지 않는다. AI 선택, 두 세션 경합, 백업 복원 및 1주 실사용도 계속 미완료다.

색상 복원은 이전 커밋 `ed25a1b`의 위 5개 소스 파일을 검토하여 선택 복원하고 로고 자산 추가를 별도 변경으로 되돌린 뒤 다시 빌드한다. 전체 저장소 reset이나 다른 작업 되돌리기는 하지 않는다. 현재 실행 중인 CRM을 보존하면서 서버 재시작이 필요한지 확인한다.
